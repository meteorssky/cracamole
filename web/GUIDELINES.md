# 前端與桌面介面 UI/UX 開發準則

適用範圍：`web/` 下所有檔案（`web/vendor/` 的第三方程式除外，不得修改），以及 §12 針對 Windows 原生桌面版（`crates/cracamole-desktop`）制定的 UI/UX 準則。
現代化視覺設計系統、標竿產品對照與互動規格書見根目錄 [`design.md`](../design.md)（本機補充診斷見 `docs/ux-redesign.md`）。**本檔的規則用「必須／不得」表示強制，用「應」表示預設、需要理由才能偏離。**

---

## 1. 不可違反的限制

1. **無建置步驟、無 Node runtime**：正式執行只靠 Rust 執行檔內嵌的靜態檔。不得引入打包器、轉譯器、框架或 npm 執行時依賴。Node 僅用於測試（`tests/e2e`）。
2. **CSP 為 `script-src 'self'`**：不得使用行內 `<script>`、`onclick=` 屬性、`eval`、`new Function`。樣式允許行內（`style-src 'unsafe-inline'`），但**應**用 class 與 token，不寫行內樣式。
3. **`web/vendor/` 唯讀**：保留 Apache LICENSE／NOTICE；不修補。需要行為調整時，在自己的適配層處理。
4. **機密不得出現在**：URL、`localStorage`／`sessionStorage`、日誌、`console.*`、DOM 屬性、錯誤訊息。密碼、私鑰、密語只存在於表單欄位與送出的請求本文；API 只回傳「是否已設定」。
5. **不得向第三方網域發出請求**（字型、CDN、分析、圖示皆需自帶）。
6. **內容語言為繁體中文**，用語依 §8。

## 2. 檔案結構

```
web/
  index.html            # 只放骨架與地標；不放業務邏輯
  css/
    tokens.css          # 唯一的設計 token 來源（顏色／間距／字級／圓角／陰影／動效）
    base.css            # reset、排版、焦點、減少動態、forced-colors
    layout.css          # 版面（登入、頂欄、連線庫抽屜、舞台、狀態列）
    components/*.css    # 每個元件一檔：button、form、badge、card、dialog、overlay、toast、keybar、banner
  js/
    main.js             # 進入點：只做組裝與啟動
    api.js              # 唯一的 fetch 封裝（錯誤正規化 {status,message,field}、逾時、401 統一處理）
    state.js            # 單一事件化狀態
    session/            # guac.js（唯一接觸 Guacamole 的地方）、reasons.js（結束原因→可行動訊息）、keys.js（輔助鍵）
    views/              # login、drawer、library、editor、stage
    ui/                 # dialog.js（唯一的對話框／確認機制）、toast.js
    util/               # dom.js、protocols.js、theme.js
  vendor/               # 第三方（唯讀）
  GUIDELINES.md
```
- 一個檔案一個職責；**超過 250 行必須拆分**。
- 新增靜態檔必須列入 `crates/cracamole-web/src/assets.rs` 的資產表（單一表、單一 `/assets/{*path}` 路由）。`every_web_file_is_served` 測試會在漏列時失敗。
- 首頁以全部內嵌資產的 SHA-256 版本路徑載入靜態資產，版本化路徑使用 `public, max-age=31536000, immutable`；未版本化路徑使用內容 ETag 與 `private, no-cache` 重新驗證，首頁及動態回應維持 `no-store`。Windows x64 的 Web API 與三種瀏覽器已驗證版本化入口與舊路徑；舊路徑的重複讀取中 Chromium、Firefox 收到 304，測試環境的 WebKit 重新取得 200。

## 3. CSS 規則

1. **所有數值走 token**：顏色、間距、字級、圓角、陰影、動效時間只能用 `var(--…)`。禁止在元件檔寫死 `#hex`、`px` 間距（1px 邊框、0 除外）。
2. **語意命名**：`--surface`、`--text-muted`、`--danger`；禁止 `--green-2`、`--gray-700` 這類值名稱用於元件。
3. **命名**：BEM 風格 `.card`、`.card__title`、`.card--active`；狀態用 `aria-*` 或 `data-state` 選擇器（`[aria-selected="true"]`），不用 `.is-xxx` 混雜。
4. **不得使用 `!important`**（唯一例外：`[hidden]{display:none!important}` 與 `prefers-reduced-motion` 覆寫）。
5. **選擇器深度 ≤ 2**；不得用 ID 作樣式選擇器。
6. **邏輯屬性優先**（`margin-inline`、`padding-block`、`inset`），為日後 RTL／直書預留。
7. **單位**：字級與間距用 `rem`；觸控目標、邊框用 `px`。**文字不得小於 14px**（等寬終端機字型除外）。CJK 文字**不得**設定負的 `letter-spacing`。
8. **必須處理的媒體查詢**：`prefers-color-scheme`、`prefers-reduced-motion`、`forced-colors`；斷點只有 `--bp-sm: 760px` 一個（行動優先，往大寫）。
9. **對比**：正文 ≥ 4.5:1、大字與 UI 邊框 ≥ 3:1；**以腳本計算 token 對，不憑目測**（新增或修改顏色時必須附上計算結果）。
10. **焦點**：每個可聚焦元素都要有 `:focus-visible` 樣式（2px 輪廓＋2px 偏移，對比 ≥ 3:1）；**不得** `outline:none` 而不補替代。
11. **動畫**：只動 `transform`／`opacity`；150–200ms；尊重 `prefers-reduced-motion`。

## 4. JavaScript 規則

1. **原生 ES module**（`<script type="module">`）；不使用全域變數；每個模組明確 `export`。
2. **嚴格模式與語法**：`const` 優先、`let` 其次、不用 `var`；`===`；不用隱式型別轉換。
3. **格式**：2 空白縮排、單引號、行寬 ≤ 100、結尾分號、一行一個語句（**禁止把多個語句塞成一行**，現有 `app.js` 的長行屬待遷移債務）。以專案 `.editorconfig`／Prettier 設定統一（僅開發工具，不進入正式執行）。
4. **DOM 安全**：插入使用者可控內容（連線名稱、主機名稱、遠端剪貼簿、錯誤訊息）**只能**用 `textContent`、`setAttribute`、`replaceChildren`。**禁止**對動態資料使用 `innerHTML`、`insertAdjacentHTML`、`outerHTML`。
5. **網路**：所有請求經 `api.js`。它負責：同源、`credentials: same-origin`、逾時、把失敗正規化為 `{status, code, message, field?}`；401 統一導向登入並關閉工作階段。元件不得直接呼叫 `fetch`。
6. **狀態**：單一 `state` 物件＋明確的事件（`state.on('connections', …)`）。元件**不得**彼此直接修改對方的 DOM；透過狀態或事件溝通。
7. **Guacamole 適配層**（`js/session/`）：全專案只有此處可以 `new Guacamole.*`。對外提供 `connect(connection, el) → Session`，`Session` 暴露：`state`（`connecting|connected|reconnecting|closed`）、`closeReason`（`remote-exit|network|auth|timeout|expired|server`）、`resize()`、`sendKeys()`、`clipboard`、`dispose()`。UI 不依賴 Guacamole 的原始碼值。
8. **資源回收**：每個 `addEventListener`、`ResizeObserver`、計時器、Guacamole client 都必須有對應的釋放；工作階段關閉時**必須**呼叫 `dispose()`。不得留下游離的 `blur`／`keydown` 監聽。
9. **錯誤處理**：不得吞錯（空的 `catch {}` 禁止）。使用者可見的錯誤必須 (a) 說明發生什麼、(b) 指出可做的動作、(c) 就地顯示（欄位旁或覆蓋層），toast 只能是補充。
10. **鍵盤**：終端機／遠端桌面取得焦點時轉送按鍵；必須提供「離開終端機」的鍵盤出口（避免焦點陷阱）；不得無條件 `preventDefault` 整個頁面的快捷鍵。
11. **可測試性**：每個互動元素有穩定的可及名稱（`aria-label` 或可見文字），供測試以 role／name 取用。**測試不得依賴 CSS class 或 DOM 結構**。

## 5. 元件規則

- **一個概念一個元件**：對話框、確認、通知、覆蓋層、分頁各只有一種實作；不得新增第二種「確認」機制（`window.confirm`／`alert`／`prompt` **禁止使用**）。
- 每個元件**必須**實作並測試狀態：預設、hover、focus-visible、active、disabled、loading、error（適用者）。
- **對話框**用原生 `<dialog>`：開啟時聚焦第一個互動元素或標題；`Esc` 關閉；關閉後焦點回到觸發者；背景不可操作。
- **按鈕**：每個視圖**最多一個**主要按鈕；危險動作用危險樣式且需二次確認；載入中 `aria-busy` 並停用，防止重複送出。
- **表單**：標籤永遠可見（placeholder 不是標籤）；錯誤用 `aria-describedby` 連結、`aria-invalid="true"`；送出時就地顯示欄位級錯誤並聚焦第一個錯誤欄位。
- **狀態不只靠顏色**：狀態點必須搭配文字或圖示。
- **圖示**：內嵌 SVG（`currentColor`）；純圖示按鈕必須有 `aria-label`。

## 5.1 現代化 UI 呈現與操作便利性準則（Modern UI & Convenience-First UX）

本專案對標現代頂級開發者與遠端運維工具（**Termius、Linear、Raycast、Warp、Microsoft Windows App**），以**「使用者操作便利性絕對優先（最少點擊、最短視線移動、零摩擦閉環）」**為核心規劃原則：

1. **無頂部標題列、畫面最大化與可收折控制塢（Zero Title Bar & Collapsible Dock）**：
   - **禁止頂部 Title Bar 佔用視窗高度**：瀏覽器本身已有分頁列與網址列，應用層**不得**再放置全寬的頂部標題列（`.topbar`）。終端機／遠端桌面舞台必須直接從視窗頂端（`y = 0`）開始渲染。
   - **單一整合控制塢與最近連線快切（Recent Session Switcher）**：所有全域與工作階段控制項整合於底部單一控制塢（`.statusbar`），除提供**「最大畫面（收折選單）」**與**「全螢幕」**切換外，並直接呈現**最近使用／剛中斷的主機快捷膠囊**，支援一鍵秒切或重連，免去反覆開關左側抽屜。
   - **連線庫抽屜覆蓋不擠壓**：當有活躍連線時，展開左側連線庫抽屜必須以**現代毛玻璃／高層級浮動覆蓋層（`data-overlay="true"`）**呈現，**不得**推擠舞台寬度而觸發遠端 PTY／RDP 重新縮放；支援點擊舞台背景或按 `Esc` 收合。
2. **萬用搜尋與即輸即連列（Omnibar Search & Quick Connect）**：
   - 連線庫頂部的搜尋框同時作為 **Omnibar（萬用搜尋與直連列）**：
     - 輸入一般文字時，即時篩選主機名稱、群組、IP、帳號或協定，並自動展開符合的群組。
     - 若輸入符合 `user@host:port` 或 `ssh://user@host`、`rdp://host` 格式，列表頂部即時浮現**「⚡ 快速新增並連線至 `user@host:port`」**行動列，按 `Enter` 直接帶入編輯器或立即連線，打破「必須先手動點新增、填滿表單才能連線」的繁瑣流程。
3. **現代化分層導覽樹：置頂釘選 ＋ 可折疊群組 ＋ 高密度單行卡片（Pinned Favorites, Collapsible Groups & Compact Rows）**：
   - **置頂常用釘選區（Pinned / Favorites ★）**：支援將最常存取的 3–5 台核心主機標記為「釘選（★）」，固定顯示於連線庫最上方，永遠不需捲動或翻找群組即可一鍵直連。
   - **可折疊群組手風琴（Collapsible Group Accordion）**：
     - 支援依「群組（Group）」組織主機（支援群組欄位與 `群組名稱 / 主機名稱` 路徑自動歸類；未分類者歸入預設群組）。
     - 每個群組以 `<details class="conn-group">` 呈現，吸附式群組標頭（`<summary>`）顯示**旋轉箭頭、群組名稱、活躍／總主機數徽章（如 `1/4 已連線`）**，懸停時提供 `[＋]` 快速於該群組新增主機；支援一鍵「全部折疊／展開」（狀態持久化於 `localStorage`）。
   - **高密度現代化列表卡片（Modern Compact Row，高度 `42px–52px`）**：
     - 廢除傳統三行肥大卡片。每筆連線採現代高密度單行／微雙行排版，單屏可瀏覽 15–20 台主機。
     - **語意化協定色彩徽章**：不同協定採用高辨識度語意色標（如 `SSH` 翠綠、`RDP` 湛藍、`VNC` 琥珀、`Telnet` 岩灰），視覺掃描 0.1 秒即可區分協定類型。
     - **懸停快顯操作列（Hover Action Bar）**：次要動作（`★ 釘選`、`✎ 編輯`、`🗐 複製`、`🗑 刪除`）於滑鼠懸停（`:hover`）或鍵盤聚焦（`:focus-within`）時平滑浮現於卡片右側，平時不佔用額外行高。
4. **每張卡片常駐連線與安全狀態（Persistent Per-Card Status & Trust Badges）**：
   - **所有卡片皆有狀態燈號与文字**：左側連線庫中的**每一張卡片**（不限於當前活躍連線）都必須常駐顯示連線與信任狀態：
     - 狀態呼吸燈（`.dot`）與狀態小膠囊：🟢 `已連線`（活躍中）、🟡 `正在連線…`（握手中）、🔴 `連線失敗（含原因摘要，如驗證失敗／逾時／待核對）`、⚪ `未連線`（待命）。
     - **斷線後狀態保留**：當連線異常中斷或使用者返回連線庫時，該張卡片**必須保留剛才的結果狀態**（而非清空為無狀態），讓使用者一眼看出剛才是哪台主機連線失敗。
     - **安全信任微徽章**：已設定 SSH `host-key` 或 RDP `server-cert-sha256` 者顯示 `🔒 已信任` 標記；設定唯讀者顯示 `唯讀` 標記。
5. **現代化表單互動：視覺分段切換器、智慧解析與名稱自動生成（Modern Editor Ergonomics）**：
   - **協定視覺分段切換器（Segmented Control）**：以一鍵切換的現代分段膠囊（`[ >_ SSH ] [ 🖥 RDP ] [ 🍎 VNC ] [ ⌨ Telnet ]`）取代傳統下拉選單，少一次點擊並同步切換預設連接埠提示。
   - **智慧貼上與免填名稱（Smart Paste & Auto-Naming）**：
     - 在「主機」欄位貼上 `ssh -p 2222 ubuntu@10.0.1.5` 或 `user@host:port` 時，自動拆解填入協定、帳號、主機與連接埠。
     - 若「連線名稱」留空，自動以 `user@host`（或 `host`）生成預設名稱，讓使用者只需貼上主機位址＋輸入密碼，即可直接按 `Enter`「儲存並連線」。
   - **就地主動指紋預檢**：編輯 SSH／RDP 連線時，提供一鍵「探測並核對指紋」按鈕，無須先連線失敗一次才能釘選身分。
6. **連線設定複製與跨端配置遷移（Connection Cloning & Config Portability）**：
   - **一鍵複製為新連線（Quick Clone / Duplicate）**：
     - **多入口觸發**：(a) 連線卡片右側懸停快顯列的 `[🗐 複製]` 按鈕、(b) 編輯對話框底部操作列的 `[複製為新連線]` 按鈕、(c) 聚焦於卡片時按 `Ctrl+D`（或 `Alt+D`）。
     - **完整繼承公開設定**：開啟新增模式的編輯器並自動帶入來源連線的所有非機密參數（`protocol`、群組、`hostname`、`port`、`username`、文字編碼、RDP 畫面與安全設定、Telnet 正規表示式、逾時與唯讀限制等）。
     - **智慧名稱序號遞增（Smart Auto-Increment）**：若原名稱結尾含數字（如 `prod-web-01` 或 `DB-1`），新名稱自動預填為 `prod-web-02` 或 `DB-2`；若無數字則預填 `原名稱 - 複製`。
     - **焦點直達修改處與信任指紋安全處理**：開啟複製表單時，**自動聚焦並全選 `hostname`（主機名稱或 IP）欄位**，方便使用者直接貼上新主機 IP。若使用者未變更 `protocol`、`hostname` 與 `port`（如僅變更帳號或唯讀設定以建立同主機分身），保留已釘選的 `host-key`／`server-cert-sha256`；一旦變更 `hostname`、`port` 或 `protocol`，儲存時**自動清除舊主機指紋**，確保新主機重新核對身分，並提示輸入新主機的密碼／私鑰。
   - **複製／貼上連線設定字串（脫敏 URI 與 JSON 快速分享／跨端遷移）**：
     - 支援將單筆或整批連線的**公開設定（絕不含密碼、私鑰、密語）**複製為標準連線字串（`ssh://user@host:port`）或脫敏設定 JSON 至剪貼簿，並支援於 Web 端或 Windows 桌面版一鍵「從剪貼簿貼上匯入設定」，解決 Web 與 Desktop 獨立資料目錄間快速同步主機清單的需求。
7. **一鍵無感剪貼簿與全域鍵盤命令面板（One-Click Clipboard & Command Palette）**：
   - **一鍵貼上與自動同步**：在支援 Async Clipboard API 的環境下，提供「一鍵貼上本機剪貼簿」直達遠端；若展開剪貼簿浮層，點擊「貼上到終端機」或按 `Ctrl+Enter` 後**自動收合浮層並將焦點歸還終端機**（按 `Esc` 亦直接關閉）。
   - **全域快捷鍵與防誤斷**：
     - 支援 `/` 或 `Ctrl+K` 喚出快速搜尋／切換面板，`↑`／`↓` 鍵在卡片間移動，`Enter` 直接連線，`Ctrl+Shift+Escape` 脫離終端機焦點陷阱。
     - 當處於 `connected` 狀態時，點擊另一台主機、按上一頁或重整頁面，**必須**先提示確認（點擊同一台活躍主機則僅收合抽屜並聚焦終端機）。
8. **行動端與觸控實機軟鍵盤（True Touch & IME Readiness）**：
   - 終端機容器配置隱藏的代理 `<textarea>` 以支援行動端軟鍵盤喚出與 CJK 輸入法（IME）組字，並搭配底部觸控輔助鍵列。

## 6. 安全相關的 UX 規則

1. 密碼／私鑰欄位：`autocomplete="new-password"`（連線機密）或 `current-password`（登入）；編輯時**不回填**，顯示「已設定」徽章與「變更」。

5. 工作階段到期前預告並允許延長；到期後清空畫面上的敏感內容並導向登入。
6. 遠端剪貼簿內容視為不可信：只當文字顯示，上限大小，不解析為 HTML。

## 12. Windows 原生桌面版 UI/UX 準則與現代商業級工作台路線（`crates/cracamole-desktop`）

Windows 原生桌面版（基於 `native-windows-gui` Win32 原生控制項）與 Web 版共用 `cracamole-store`、`guacd` 及協定核心。目標體驗須對標現代商業級遠端桌面與終端機工具（如 **Termius Desktop、MobaXterm、Royal TS、Microsoft Windows App**），以**現代化視覺階層**與**極致操作便利性**取代傳統單一畫面切換式（Single-View Swap）原型：

### 12.1 現代商業級桌面體驗準則（Modern Commercial Desktop UX Principles）

1. **現代雙欄分割工作台架構（Modern Split-Pane Workbench）**：
   - **左側：常駐可收折導覽欄（Collapsible Navigation Sidebar，寬 `260px`）**：
     - **頂部 Omnibar 即時篩選與快速連線**：輸入關鍵字即時過濾群組與主機；輸入 `user@host:port` 按 `Enter` 可直接快速建立並連線。
     - **緊湊圖示化工具列**：提供 `[＋新增]`、`[🗐複製]`、`[✎編輯]`、`[🛡核對身分]`、`[🗑刪除]`，並依是否選取主機動態啟停按鈕，避免無效點擊。
     - **可折疊群組與高密度狀態清單**：支援群組階層與釘選常用主機，每列清晰呈現 `[狀態燈號] [協定] 主機名稱 — user@host:port [🔒已信任]`；連線建立後側欄可保持顯示以便秒切其他主機，或點擊 `[◀ 收折側欄]` 讓遠端畫布取得 100% 視窗寬度。
   - **右側：無縫主工作舞台（Seamless Main Stage）**：
     - **頂部 36px 扁平工作階段工具列（Session Header Bar）**：左側顯示側欄切換鈕、當前連線呼吸燈、主機名稱與加密／唯讀徽章，以及**最近連線快切選單**；右側集中排列 `[📋 一鍵貼上]`、`[⌨ Ctrl+Alt+Del]`（RDP）、`[⛶ 全螢幕]`、`[🔌 中斷連線]`，並將 `[🚪 登出]` 獨立置於最右端防誤觸。
     - **中央 100% 無感直連畫布（Direct-Focus Canvas）**：遠端畫面（`ImageFrame`）填滿舞台剩餘空間，採用深色沉穩背景襯托遠端畫面；**徹底隱藏底部突兀的密碼圓點輸入框**（將 `remote_input` 設為 `1×1` 幕後鍵盤捕捉器），滑鼠點擊遠端畫面任意處即直接輸入文字與快捷鍵。
     - **底部 24px 現代狀態列（Status Footer）**：分區顯示即時系統回饋（如 `已連線`、`已同步系統剪貼簿`）、遠端畫面解析度（如 `1920×1080`）、終端機文字編碼（`UTF-8`）與工作階段到期倒數。
2. **零摩擦鍵鼠操作便利性（Zero-Friction Ergonomics）**：
   - **開箱即打（Auto-Focus）**：啟動時若帳號已有預設值（`admin`），焦點自動落於密碼框；登入後自動聚焦連線清單並預設選取第一筆（上次使用）主機——**使用者從啟動程式到連上第一台主機，只需「輸入密碼 → 按兩下 `Enter`」**！
   - **直覺雙擊、快捷鍵與右鍵選單**：
     - 清單項目支援**滑鼠雙擊（`OnListBoxDoubleClick`）**與 **`Enter` 鍵直接連線**、`Delete` 鍵刪除、右鍵快顯選單（連線／編輯／複製／核對身分／刪除）。
     - 新增／編輯面板支援 `Enter` 直接「儲存並連線」（或儲存）、`Esc` 取消返回。
3. **智慧表單、完整四協定與原生檔案對話框（Smart Editor & Native Dialogs）**：
   - **四協定完整對齊**：編輯器（`windows_editor.rs`）支援 `ssh`、`rdp`、`vnc`（macOS 螢幕共享 ARD 與 VNC 密碼）、`telnet`，切換協定時自動顯示預設埠號（22 / 3389 / 5900 / 23）並動態切換專屬設定區。

4. **Win32 自動化測試契約守則（Test Harness Compatibility）**：
   - 現有 PowerShell 自動化測試（`tests/windows_telnet.ps1`、`tests/windows_ssh.ps1`、`tests/windows_rdp_full.ps1`）依賴特定 Win32 控制項結構：
     - 視窗標題必須以 `cracamole — Windows` 開頭。
     - 階段一改動在不修改測試腳本時，維持 `Edit` 控制項 `13` 個、`ComboBox` `3` 個；階段二新增搜尋框、群組欄位或按鈕時，**必須同步更新 `tests/*.ps1` 的控制項索引與數量斷言**，確保自動化驗收 100% 通過。
     - 核心按鈕文字（`登入`、`新增`、`編輯`、`刪除`、`核對身分`、`連線`、`中斷連線`、`貼上`、`重新載入`、`登出`、`儲存`、`取消`）與關鍵狀態列退場文字（`已登出，請重新登入。`、`連線已結束或失敗。`）須保持相容。
